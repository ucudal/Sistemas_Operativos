# Sistemas Operativos

Repositorio oficial del curso **Sistemas Operativos** de la Universidad Católica del Uruguay (UCU).

Este repositorio contiene la documentación académica y docente del curso, mantenida en formato Markdown y publicada mediante **MkDocs** y **GitHub Pages**.

## Contenido

- Propuesta académica y didáctica
- Guía docente
- Documentación de las unidades temáticas
- Materiales y recursos del curso

## Desarrollo local

Instalar MkDocs y ejecutar:

```bash
mkdocs serve
```

Luego abrir:

```
http://127.0.0.1:8000
```

## Publicación

Generar el sitio:

```bash
mkdocs build
```

Publicar en GitHub Pages:

```bash
mkdocs gh-deploy
```

## Filosofía del proyecto

La documentación forma parte del propio curso y constituye la fuente de referencia para estudiantes y docentes. Se mantiene bajo control de versiones y evoluciona junto con la asignatura, procurando preservar la coherencia entre la propuesta académica, la metodología de enseñanza, los contenidos y las estrategias de evaluación.
