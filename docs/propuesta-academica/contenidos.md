# Contenidos

Los contenidos del curso se organizan a partir de los principales problemas de ingeniería que un sistema operativo debe resolver para administrar eficientemente los recursos de una computadora.

Esta organización procura favorecer una comprensión integrada de los distintos mecanismos estudiados, destacando el problema que cada uno busca resolver y las relaciones existentes entre ellos.

---

## [Unidad 1. Fundamentos de los Sistemas Operativos](../unidades/1-fundamentos.md)

**Problema de ingeniería**

¿Cómo proporcionar una plataforma común para la ejecución de aplicaciones sobre diferentes arquitecturas de hardware?

**Contenidos**

- Introducción a los sistemas operativos
- Evolución histórica
- Arquitectura de los sistemas operativos
- Virtualización

## ["Unidad 9. Herramientas de Desempeño](../unidades/9-observacion-proteccion.md)

**Problema de ingeniería**

¿Qué sucede cuando un programa o un usuario utiliza los recursos del sistema operativo de una manera que compromete su funcionamiento, seguridad o disponibilidad?

**Contenidos**

- Procesos.
- Archivos.
- Autenticación.
- OpenSSH y firewall.
- Problemas preparados.

Integra los conceptos desarrollados a lo largo del curso mediante la observación y el análisis del comportamiento de un sistema operativo en ejecución, prestando especial atención a situaciones de uso indebido, abuso de recursos y configuraciones que pueden comprometer su funcionamiento.
