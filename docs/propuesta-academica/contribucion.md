# Contribución a la formación profesional

El curso contribuye a la formación de profesionales capaces de comprender la plataforma sobre la cual se ejecutan las aplicaciones que desarrollan, despliegan y mantienen.

El conocimiento de los sistemas operativos permite interpretar el comportamiento del software, comprender la interacción entre las aplicaciones y el hardware, analizar problemas de desempeño y seguridad y seleccionar las herramientas más adecuadas para resolver los desafíos propios de la práctica profesional.

La asignatura promueve una forma de pensar orientada a la ingeniería: comprender un problema, identificar las alternativas disponibles, seleccionar la solución más adecuada considerando criterios técnicos y justificar las decisiones adoptadas.

Desde esta perspectiva, los sistemas operativos constituyen una herramienta fundamental para comprender cómo se organiza y administra la infraestructura informática sobre la que se construyen las soluciones tecnológicas.
