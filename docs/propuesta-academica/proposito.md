# Propósito del curso

El propósito del curso es que los estudiantes comprendan cómo un sistema operativo organiza recursos limitados para satisfacer múltiples demandas de forma eficiente, segura y correcta.

A partir de esta pregunta central, la asignatura presenta los principales mecanismos que permiten administrar el procesador, la memoria, el almacenamiento, los dispositivos de entrada y salida y la ejecución concurrente de programas, analizando los problemas que dichos mecanismos buscan resolver y las alternativas disponibles para hacerlo.

Más que memorizar algoritmos o estructuras particulares, se busca que los estudiantes desarrollen la capacidad de analizar problemas propios de los sistemas operativos, comprender los compromisos involucrados en las distintas soluciones y fundamentar técnicamente la selección de una alternativa en función del contexto.
