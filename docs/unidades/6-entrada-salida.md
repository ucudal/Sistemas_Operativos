# Unidad 6. Entrada y Salida

## Descripción

Esta unidad estudia los mecanismos que utilizan los sistemas operativos para administrar la comunicación entre las aplicaciones y los dispositivos de entrada y salida.

A partir de la diversidad de dispositivos, velocidades y formas de operación, se analizan las abstracciones y mecanismos que permiten ofrecer una interfaz uniforme para el acceso al hardware, coordinar las transferencias de datos y optimizar el desempeño del sistema.

La unidad presenta los principales componentes del subsistema de entrada y salida, destacando las decisiones de diseño que permiten desacoplar las aplicaciones de las particularidades de cada dispositivo físico.

## Objetivos de aprendizaje

Al finalizar esta unidad se espera que el estudiante sea capaz de:

- comprender los problemas asociados a la comunicación entre aplicaciones y dispositivos físicos;
- reconocer el papel del sistema operativo como intermediario entre el hardware y las aplicaciones;
- comprender los principales mecanismos utilizados para coordinar las operaciones de entrada y salida;
- reconocer las estrategias empleadas para mejorar el desempeño del subsistema de entrada y salida.

## Resultados esperados

Al finalizar la unidad el estudiante:

- explica cómo el sistema operativo proporciona una interfaz uniforme para dispositivos con características diferentes;
- interpreta el funcionamiento de controladores de dispositivos, interrupciones y acceso directo a memoria como mecanismos de coordinación de las operaciones de entrada y salida;
- compara distintas estrategias de transferencia de datos considerando eficiencia y utilización de recursos;
- relaciona el empleo de buffers, cachés y planificación de entrada/salida con la mejora del desempeño global del sistema.

## Contenidos

- El subsistema de entrada y salida.
- Dispositivos y controladores.
- Interfaz entre aplicaciones y dispositivos.
- Interrupciones.
- Acceso directo a memoria (DMA).
- Transferencias síncronas y asíncronas.
- Planificación de entrada y salida.
- Buffers, cachés y spooling.
- Manejo de errores en operaciones de entrada y salida.
- Desempeño del subsistema de entrada y salida.
