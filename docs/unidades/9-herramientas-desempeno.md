# Unidad 9. Observación y Desempeño del Sistema

## Descripción

Esta unidad integra los conceptos desarrollados a lo largo del curso mediante la observación y el análisis del comportamiento de un sistema operativo en ejecución.

A través del uso de herramientas de monitoreo y diagnóstico, se estudia cómo los distintos mecanismos de administración de procesos, memoria, dispositivos y sistemas de archivos se manifiestan durante la ejecución de aplicaciones reales.

La unidad promueve el desarrollo de una visión integradora del funcionamiento del sistema operativo, utilizando la observación como herramienta para interpretar, validar y fundamentar el comportamiento del sistema.

## Objetivos de aprendizaje

Al finalizar esta unidad se espera que el estudiante sea capaz de:

- comprender el valor de la observación como herramienta para interpretar el funcionamiento de un sistema operativo;
- reconocer los principales indicadores utilizados para evaluar el comportamiento del sistema;
- comprender cómo las herramientas de monitoreo permiten visualizar los mecanismos estudiados durante el curso;
- integrar los conceptos desarrollados en las distintas unidades mediante el análisis de situaciones reales.

## Resultados esperados

Al finalizar la unidad el estudiante:

- utiliza herramientas de observación para obtener información sobre el comportamiento del sistema operativo;
- interpreta indicadores relacionados con procesos, memoria, almacenamiento y dispositivos;
- relaciona la información proporcionada por las herramientas con los mecanismos estudiados durante el curso;
- fundamenta conclusiones acerca del comportamiento de un sistema operativo a partir de la evidencia observada.

## Contenidos

- Observación del comportamiento del sistema operativo.
- Indicadores de desempeño.
- Monitoreo de procesos.
- Observación del uso de memoria.
- Observación del subsistema de entrada y salida.
- Observación del sistema de archivos.
- Herramientas de monitoreo y diagnóstico.
- Interpretación de métricas del sistema.
